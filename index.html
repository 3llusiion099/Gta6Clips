Politica de Privacidade

Ultima atualizacao: 05 de outubro de 2026

Esta Politica de Privacidade descreve como o aplicativo GTA6 Clips lida com as informacoes ao usar os servicos do TikTok.

1. Informacoes que Coletamos

O aplicativo GTA6 Clips e uma ferramenta de automacao pessoal que opera localmente. Nao coletamos, armazenamos ou compartilhamos quaisquer dados pessoais dos utilizadores.

2. Uso de Dados

Quaisquer dados acessados atraves das APIs do TikTok sao usados exclusivamente para o funcionamento do aplicativo. Nenhuma informacao e retida ou utilizada para outros fins.

3. Servicos de Terceiros

O aplicativo interage com a API do TikTok. O uso que fazemos dela esta sujeito aos termos e politicas de privacidade do proprio TikTok.

4. Contato

Se tiver alguma duvida sobre esta politica, pode entrar em contacto atraves do repositorio do projeto no GitHub.
