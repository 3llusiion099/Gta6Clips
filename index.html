Política de Privacidade

Última atualização: 05 de outubro de 2026

Esta Política de Privacidade descreve como o aplicativo GTA6 Clips ("nós", "nosso") lida com as informações ao usar os serviços do TikTok.

1. Informações que Coletamos

O aplicativo GTA6 Clips é uma ferramenta de automação pessoal que opera localmente. Não coletamos, armazenamos ou compartilhamos quaisquer dados pessoais dos utilizadores. Todas as operações são realizadas no seu próprio computador.

2. Uso de Dados

Quaisquer dados acessados através das APIs do TikTok são usados exclusivamente para o funcionamento do aplicativo (como o upload de vídeos para o Inbox do seu próprio perfil). Nenhuma informação é retida ou utilizada para outros fins.

3. Serviços de Terceiros

O aplicativo interage com a API do TikTok. O uso que fazemos dela está sujeito aos termos e políticas de privacidade do próprio TikTok.

4. Alterações a Esta Política

Podemos atualizar esta política periodicamente. Quaisquer alterações serão publicadas nesta página.

5. Contato

Se tiver alguma dúvida sobre esta política, pode entrar em contacto através do repositório do projeto no GitHub.
